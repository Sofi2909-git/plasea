# PLASEA — Plataforma de Seguimiento Académico

Prototipo web para detectar a tiempo, durante cada corte, a los estudiantes que están perdiendo o en riesgo de perder una asignatura, y para medir su continuidad entre semestres. Facultad de Ingeniería de Sistemas, Universidad Simón Bolívar, sede Cúcuta. Proyecto de la asignatura Gestión de Proyectos.

> Prototipo académico. Opera únicamente con datos ficticios.
